## Description

Add `suspend fun update(id: Long, title: String)` and `suspend fun delete(id: Long)` to `NoteRepository` /
`NoteDao` / `NoteRepositoryImpl`. Add edit and delete affordances to each row in `CalendarNoteList`, with
`CalendarEditNoteDialog` mirroring `TodoEditTaskDialog`'s pattern (T-004). Blank-title guard, same rule as
tasks and as note creation. This completes full CRUD for notes.

## Acceptance

- Editing a note on the selected date updates its title in that date's list only.
- Deleting a note removes it from that date's list; if it was the last note on that date, the date's
  "has notes" marker disappears.
- `NoteEditAndDeleteTest` (fake repository): edit changes the title, keeps the date; delete removes the
  note; delete of an unknown id is a no-op.
- Maps to DoD criteria 7, 22, 23 — and closes out the full note-CRUD requirement (DoD 6–7, 19–25 together).
