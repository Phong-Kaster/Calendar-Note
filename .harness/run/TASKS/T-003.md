## Description

Add `suspend fun setDone(id: Long, done: Boolean)` and `suspend fun deleteTask(id: Long)` to
`TaskRepository` / `TaskDao` (`@Query` update + `@Delete` or `@Query("DELETE FROM tasks WHERE id = :id")`)
/ `TaskRepositoryImpl`. Add a checkbox (toggles done) and a delete affordance to `TodoTaskItem`, wired
through `TodoViewModel`. Done tasks render with strike-through / de-emphasised style. Extend
`FakeTaskRepository` with the same two operations.

## Acceptance

- Tapping a task's checkbox flips its done state in the list; tapping again flips it back.
- Deleting a task removes it from the list immediately.
- `TaskToggleAndDeleteTest` (fake repository): toggle done → not-done → done again; delete removes the
  task; deleting an unknown id is a no-op (no crash, list unchanged).
- Maps to DoD criteria 4, 13, 14.
