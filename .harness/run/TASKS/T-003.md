## Description

Collect `PlayerRepository.state` in `LibraryViewModel` into `LibraryUiState` (`playback: PlaybackState`). When `playback.currentSong != null`, `CoreLayout(bottomBar = …)` shows `MiniPlayerBar`: `SongArtwork` placeholder (shared component from T-001), marquee title, artist, play/pause `IconButton` (content-description = `R.string.pause` / `R.string.play`, drawables `R.drawable.ic_player_play` / `ic_player_pause` provided by the Iteration), a thin progress line from `progressFraction`. Tapping the bar body calls `onOpenNowPlaying` → `safeNavigate(R.id.toNowPlaying)` (action wired by the Iteration). Playing row in the list is visibly highlighted. Overlay/bottom bar must not cover the last list item (list content padding). Previews for loaded/playing/paused.

## Acceptance

User can now see what is playing at the bottom of the library at all times, pause/resume from it (also when changed from the notification), and tap it to reach Now Playing. DoD 12, 18 (part).
