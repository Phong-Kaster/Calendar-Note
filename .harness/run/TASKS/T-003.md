## Description

Playback through Media3 (A-001). `MusicPlaybackService : MediaSessionService` owns an ExoPlayer
(`REPEAT_MODE_ALL`, audio attributes for music, handle audio focus + becoming-noisy) wrapped in a
`ForwardingPlayer` whose `seekToPrevious()` goes to the previous media item (A-004) so the in-app button and the
notification's button behave the same. `PlayerRepository` is the domain seam: `playbackState: StateFlow<PlaybackState>`
(current song id/title/artist, isPlaying, hasQueue), `playQueue(songs, startIndex)`, `togglePlayPause()`,
`next()`, `previous()`, `connect()`/`release()`. `MusicViewModel` gains the playback actions and mirrors
`playbackState` into `MusicUiState`; `NowPlayingBar` shows title/artist and previous / play-pause / next.
