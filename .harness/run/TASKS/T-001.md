## Description

`CoreLayout` paints every screen black while `MyApplicationTheme` follows the phone's light/dark mode and
dynamic colour, so in light mode any colour taken from the theme is dark-on-black. Make the app use one fixed
dark colour scheme and a matching window/system-bar style.

## Acceptance

- `MyApplicationTheme` always uses one `darkColorScheme(...)` that sets **every** role it defines (primary,
  onPrimary, primaryContainer, onPrimaryContainer, secondary…, tertiary…, background, onBackground, surface,
  onSurface, surfaceVariant, onSurfaceVariant, outline, outlineVariant, error, onError, …); no
  `isSystemInDarkTheme()` and no dynamic colour branch. Colour values live in `Color.kt`.
- `CoreLayout.kt` takes its background from `MaterialTheme.colorScheme.background` (no `Color.Black`).
- `CoreActivity.kt` calls `enableEdgeToEdge(statusBarStyle = SystemBarStyle.dark(...), navigationBarStyle = SystemBarStyle.dark(...))`.
- `res/values/themes.xml` sets `android:windowLightStatusBar` to `false` and a dark window background.
- Observable: in the phone's light mode the status-bar icons are light and screens stay dark.
