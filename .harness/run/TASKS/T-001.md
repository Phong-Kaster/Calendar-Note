## Description

Read MediaStore `ALBUM_ID` into `SongRow.albumId: Long? = null` (default: `SongMapperTest` builds `SongRow(...)`).
Add plain-Kotlin `albumArtUriFor(albumId: Long?): String?` → `"content://media/external/audio/albumart/<id>"`, `null`
for `null` or `<= 0`. `Song` gains `albumArtUri: String? = null` (default keeps every existing `Song(...)` compiling).
`SongRow.toDomain()` fills it. `Song.toMediaItem()` sets `MediaMetadata.Builder().setArtworkUri(Uri.parse(it))` when
present; `MediaItem.toSongOrNull()` reads it back (`artworkUri?.toString()`).
