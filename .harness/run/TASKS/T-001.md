## Description

Make the app open to a real library of on-device songs.
- `Song` (domain, Android-free): `id: Long`, `title`, `artist`, `album`, `durationMs`, `contentUri: String`, `artworkUri: String?` (`content://media/external/audio/albumart/<albumId>`).
- `MusicRepository { suspend fun getSongs(): List<Song> }`; impl queries `MediaStore.Audio.Media.EXTERNAL_CONTENT_URI` (`IS_MUSIC != 0`, sorted by title, recipe F: `withContext(ioDispatcher)`, fail-soft `emptyList()`, TAG in companion, `CancellationException` rethrown). Constructor: `context: Context`, `ioDispatcher`. `SongMapper.kt` holds `data class MediaStoreSongRow(id, title, artist, album, albumId, durationMs)` and `fun MediaStoreSongRow.toDomain(): Song` (JVM-testable; blank/`<unknown>` artist → localizable fallback handled by UI, keep raw).
- `formatDuration(ms): String` → `m:ss` (`h:mm:ss` from 1 h).
- Library screen (`LibraryFragment : CoreFragment`, ViewModel, immutable `LibraryUiState` with defaults: `songs`, `isLoading`, `hasPermission`, derived `showEmptyState`): request `READ_MEDIA_AUDIO` (API ≥ 33) or `READ_EXTERNAL_STORAGE` (≤ 32) with accompanist `rememberPermissionState` following the idea (not the imports) of `HomeRequestPermission.kt`; granted → load songs; denied → an explanation plus a button that re-requests, or opens app settings after "permanently denied"; empty list → empty-state message with icon; loading state. List is a scrollable `LazyColumn` of `SongItem`(placeholder music-note icon, title, artist, duration; single-line with marquee/ellipsis). Re-check permission and reload on `RESUMED` (user may grant in Settings). Row click callback `onSongClick(index)` exists but is a no-op now (T-002 wires it).
- Status bar: the library screen must pad for the status bar (use `CoreTopBar`-free `statusBarsPadding()` or a top bar that pads); the activity is edge-to-edge with zero default insets.
- Theme (Constraint fix): keep the `MyApplicationTheme(darkTheme, dynamicColor, content)` signature (CoreFragment calls it with defaults) — ignore `darkTheme`, always dark; force a dark, complete `darkColorScheme` (every role filled, incl. background/surface/onBackground/onSurface/primary/onPrimary/container roles); `dynamicColor` default false; `CoreLayout` ground = `MaterialTheme.colorScheme.background` (no `Color.Black`); all new text/icon colours from `MaterialTheme.colorScheme`.
- Tests: mapper, duration formatting (0 ms, 59 s, 61 s, 1 h+), `LibraryUiState.showEmptyState` (granted+not loading+empty → true; loading → false; not granted → false).
