## Description

A new Music screen (bottom-bar tab, start destination — wired by the Iteration) that asks for the audio
permission with Accompanist (API 33+ `READ_MEDIA_AUDIO`, below `READ_EXTERNAL_STORAGE`), then lists every
on-device song (MediaStore `IS_MUSIC != 0`, sorted by title) with title and artist. States: loading,
permission denied (message + grant button; after a permanent denial the button opens app Settings), empty
("no songs"), and the list (`LazyColumn`, keyed rows). Re-checks the permission on resume so granting in
Settings shows the list without restarting.

## Acceptance

- `audioPermissionFor(33)` / `(34)` → `"android.permission.READ_MEDIA_AUDIO"`; `(32)` / `(24)` →
  `"android.permission.READ_EXTERNAL_STORAGE"`.
- `SongRow.toDomain()` → `null` when duration ≤ 0; blank title → display name without extension; `"<unknown>"`
  or blank artist → `null`.
- `MusicUiState(...).screenContent` → `PermissionDenied` when not granted, `Loading` while loading, `Empty`
  when granted with no songs, `Songs` otherwise.
- `SongRepositoryImpl` queries on `ioDispatcher`, fails soft to `emptyList()`, re-throws `CancellationException`.
- The Layout is a private previewable `MusicLayout(uiState, lambdas = {})` with one named preview per state.
