## Description

Remove two permissions the app declares but never uses — `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`
— and every line of code that requests or checks them. Keep `android.permission.VIBRATE`, `INTERNET`,
`ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED` exactly as
they are — if you find a reason one of those is dead too, **say so in your report and leave it alone**;
that is a separate decision for the human, not part of this task.

A manifest with a permission gone and UI still asking for it is worse than either state alone, so this
task **is** both the manifest edit and the UI edit together — do not split it.

**What to do, file by file:**

1. `AndroidManifest.xml` — remove the two location `<uses-permission>` lines
   (`ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`). Leave `VIBRATE` and the other five untouched.
2. `HomeRequestPermission.kt` — remove `onLocationGranted`, the `rememberMultiplePermissionsState` over
   the two location permissions, `hasRequestedLocation`, the local `requestLocation()` function, and every
   place `locationGranted`/`locationPermissions.allPermissionsGranted` feeds into `showBottomSheet` —
   **without changing what the notification and exact-alarm terms of that same predicate do.** Remove the
   two location arguments passed to `HomePermissionBottomSheet`.
3. `HomePermissionBottomSheet.kt` — remove the `isLocationEnable`/`onGrantLocation` parameters (both the
   public composable and the private layout composable) and the Location `PermissionSwitch` block and its
   preceding `Spacer`. The Notification and (Android 12+) Exact-alarm switches must keep working exactly
   as they do today.
4. `HomeFragment.kt` — remove the `isLocationGranted` import and the location branch inside
   `checkPermission()`; keep the notification branch. Remove the (already empty) `onLocationGranted`
   lambda passed to `HomeRequestPermission`.
5. `PermissionUtil.kt` — remove `isLocationGranted`; it becomes fully dead once the call sites above are
   gone. Leave every other function in that file alone (this is a reusable skeleton project and its other
   unused helpers are not this task's business).
