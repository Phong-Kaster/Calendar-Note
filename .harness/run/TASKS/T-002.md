## Description

- `PlaybackService : MediaSessionService` holding an ExoPlayer (`AudioAttributes` USAGE_MEDIA/CONTENT_TYPE_MUSIC, `handleAudioFocus=true`, `setHandleAudioBecomingNoisy(true)`), a `MediaSession` with `setSessionActivity` = PendingIntent to `MainActivity` (notification tap opens the app), `onGetSession`, release in `onDestroy`, `onTaskRemoved` stops the service if not playing. Override `MediaSession.Callback.onAddMediaItems` to rebuild each item with `setUri(requestMetadata.mediaUri ?: …)`; annotate unstable-API use with `@androidx.annotation.OptIn(UnstableApi::class)`. Default `DefaultMediaNotificationProvider` (prev/play-pause/next, title/artist/artwork from `MediaMetadata`).
- Domain (Android-free): `PlaybackState(currentSong: Song?, isPlaying, positionMs, durationMs, currentIndex, queueSize, shuffleEnabled, repeatMode)` with derived `progressFraction`, `hasNext`, `hasPrevious`; `RepeatMode { Off, All, One }` with `next()` cycling.
- `PlayerRepository`: `val state: StateFlow<PlaybackState>`; `fun playQueue(songs: List<Song>, startIndex: Int)`, `fun togglePlayPause()`, `fun skipToNext()`, `fun skipToPrevious()`, `fun seekTo(positionMs: Long)`, `fun setShuffleEnabled(enabled: Boolean)`, `fun setRepeatMode(mode: RepeatMode)`. Full surface now so T-003/T-004 never edit it.
- `PlayerRepositoryImpl(context, …)`: builds `SessionToken(context, ComponentName(context, PlaybackService::class.java))`, connects a `MediaController` on the main thread at construction (use `ListenableFuture.addListener(…, ContextCompat.getMainExecutor(context))` — no extra library), Player.Listener → `_state`, position ticker (~500 ms) only while playing, every command is posted to the main thread by the repository (ViewModels call plain `fun`s, never inside `Dispatchers.IO`); set BOTH `MediaItem.localConfiguration` URI and `RequestMetadata.mediaUri`; calls before the controller is ready are queued/ignored fail-soft. Queue lives in the player as `MediaItem`s (`MediaItemMapper`: `Song.toMediaItem()` with `MediaMetadata` title/artist/album/artworkUri, mediaId = song id).
- Library: `onSongClick(index)` → `playerRepository.playQueue(uiState.songs, index)`; on first play request `POST_NOTIFICATIONS` (API ≥ 33) via accompanist, playback proceeds regardless of the answer.
- Tests: `PlaybackState` derived values, `RepeatMode.next()` cycle.
