## Description

Keep Media3's standard MediaStyle notification. In `MusicPlaybackService.onCreate` install a
`DefaultMediaNotificationProvider` via `setMediaNotificationProvider(...)` with small icon
`R.drawable.ic_notification_music`. Give the notification the theme's primary as accent colour and Material Symbols
action icons, using what Media3 1.8.0 supports (the Iteration gives the exact API/resource names in the Brief). No
`RemoteViews` or custom content view. Existing session behaviour (session activity, `onTaskRemoved`,
`QueuePolicyPlayer`, `PlayableItemsCallback`) must stay unchanged.
