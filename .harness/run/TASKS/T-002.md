## Description

A new Music screen (start destination, first bottom-bar tab — A-002) that asks for the audio permission and lists
music already on the device from `MediaStore.Audio.Media` (`IS_MUSIC != 0`, sorted by title). Each row: title,
artist (fallback string when `<unknown>`/blank), duration (`m:ss`). States: permission needed (explanation + button
that requests the permission, or opens app settings when permanently denied), loading, empty ("no songs"), list.
Re-check permission on resume so granting from settings loads the list without restart.

- `Song(id: Long, title: String, artist: String?, durationMs: Long, contentUri: String)` — Android-free.
- `SongRepository.getSongs(): Outcome<List<Song>>` (fail-soft). Impl queries `ContentResolver` on `ioDispatcher`
  using the query spec from `SongMapper.kt`; builds the content URI with `ContentUris`.
- `SongMapper.kt` holds a plain `SongQuery` (projection, selection, sortOrder) and a plain `SongRow` →
  `Song` mapping so both are JVM-testable (C-04).
- `MusicViewModel(songRepository)` exposes `uiState: StateFlow<MusicUiState>`; `onPermissionResult(granted: Boolean)` drives
  the load.
