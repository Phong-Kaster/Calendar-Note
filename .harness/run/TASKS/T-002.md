## Description

First working vertical slice of the To-do feature, following the `Post` vertical as the template
(`domain/model/Post.kt` → `domain/repository/PostRepository.kt` → `data/database/local/entity/PostEntity.kt`
+ `dao/PostDao.kt` → `data/mapper/PostMapper.kt` → `data/repository/impl/PostRepositoryImpl.kt` →
`ui/fragment/home/*`, Recipe B in `.claude/repository-layer.md`):

- `Task` domain model: `id: Long`, `title: String`, `isDone: Boolean`, `createdAt: Long` (assumption —
  PRD names only a title; record this shape as an assumption, see `STATE.md`).
- `TaskEntity` (`@Entity(tableName = "tasks")`, `@PrimaryKey(autoGenerate = true) val id: Long = 0`,
  matching the `UserActionEntity` convention) and `TaskDao` with `observeAll(): Flow<List<TaskEntity>>`
  and `suspend fun upsert(entity: TaskEntity)`.
- `TaskMapper.kt`: `TaskEntity.toDomain()`, `Task.toEntity()`.
- `TaskRepository` interface (`domain/repository/`): `val tasksFlow: Flow<List<Task>>`,
  `suspend fun addTask(title: String)`. Reject blank/whitespace-only titles at this layer (assumption —
  no error UI, the call is a no-op; see `STATE.md`).
- `TaskRepositoryImpl` (Room-only recipe, `data/repository/impl/`).
- `TodoViewModel` / `TodoUiState` / `TodoFragment` (extends `CoreFragment`, matches `HomeFragment`'s
  shape: thin fragment + private `TodoLayout(uiState, onAddTask)` composable + `@Preview`). Text field +
  add button + `LazyColumn` of `TodoTaskItem`. Use `customizedTextStyle(...)` from `ui/theme/Type.kt` for
  `Text`, not `MaterialTheme.typography` (SettingFragment is the better reference than HomeFragment here).
- `FakeTaskRepository` in the test source set: an in-memory `MutableStateFlow<List<Task>>`-backed fake
  implementing `TaskRepository`, for this and later To-do tasks to reuse and extend.
- `TaskRepositoryCreateReadTest`: adding a task makes it observable in `tasksFlow`; a blank title is
  rejected (list unchanged). Use `runBlocking` + `Flow.first()` / collecting into a list — no
  `Dispatchers.Main`, no ViewModel instantiation.

Do **not** touch `AppDatabase.kt`, `Migration.kt`, `injection/*`, `navigation_graph.xml`,
`CoreBottomBar.kt`/`BottomBarDestination.kt`, or `strings.xml` — the Iteration wires all of those itself
after this Phase.
