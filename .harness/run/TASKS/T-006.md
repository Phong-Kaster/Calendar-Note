## Description

Second vertical slice, and the largest task in the run — kept as one checkpoint (rather than splitting the
"add note" and "mark dates with notes" behaviors) because they are two views of the same underlying
date-scoped query and splitting them would leave one half with no independent observable behavior.

- `Note` domain model: `id: Long`, `epochDay: Long` (the date, stored as `LocalDate.toEpochDay()` — no
  existing `LocalDate` `TypeConverter` in this repo, only `DateConverter` for `java.util.Date`; storing a
  plain `Long` avoids needing a new converter and keeps date-range queries simple integer comparisons),
  `title: String`, `createdAt: Long`.
- `NoteEntity` (`@Entity(tableName = "notes")`, indexed on `epochDay`) + `NoteDao`:
  `observeByEpochDay(epochDay: Long): Flow<List<NoteEntity>>`,
  `observeEpochDaysWithNotesBetween(start: Long, end: Long): Flow<List<Long>>` (drives the "has notes"
  marker for the visible month), `suspend fun insert(entity: NoteEntity)`.
- `NoteMapper.kt`, `NoteRepository` interface + Room-backed `NoteRepositoryImpl`.
- `CalendarUiState` gains: `selectedDate: LocalDate?`, `notesOfSelectedDate: List<Note>`,
  `datesWithNotes: Set<LocalDate>` (recomputed whenever the visible month changes).
- `CalendarViewModel` gains `noteRepository: NoteRepository` (constructor param — the Iteration updates
  `ViewModelModule.kt`'s binding after this Phase), `selectDate(date)`, `addNote(title)`.
- `CalendarDayCell` renders a marker (e.g. a dot) when its date is in `datesWithNotes`; tapping a day
  calls `selectDate`. `CalendarNoteList` shows `notesOfSelectedDate` only. `CalendarAddNoteRow` is the
  title input + add button, enabled only when a date is selected.
- `FakeNoteRepository` (in-memory, `MutableStateFlow<List<Note>>`-backed) + `NoteDateScopingTest`: a note
  added to one date is returned for that date and not for another; a month's `datesWithNotes` contains
  exactly the dates with notes, excluding dates in adjacent months; an empty date returns an empty list.

Do **not** touch `AppDatabase.kt`, `Migration.kt`, `injection/*`, or `strings.xml` — the Iteration wires
those itself.

## Acceptance

- Tapping a date, typing a note title, and adding it shows the note under that date only; other dates'
  note lists are unaffected.
- A date with at least one note renders differently (marker) from one without, and the marker updates as
  notes are added.
- `NoteDateScopingTest` passes under `gradlew.bat test`.
- Maps to DoD criteria 6, 19, 20, 21, 24, 25.
