S-02Đề nghị: tầng loopProposed: loop tier

cd <repo> && <lệnh> bị tính là nhiều thao tác và bị chặn

cd <repo> && <command> counts as multiple operations and is refused

Một dòng cd … && ./gradlew … hay cd … && git … bị từ chối dù phần lệnh chính có thể được phép; git -C <path> cũng không khớp mẫu Bash(git status*). Chạy cd ở một lời gọi riêng (thư mục làm việc được giữ) thì các lệnh sau khớp mẫu bình thường.

A cd … && ./gradlew … or cd … && git … line is refused even when the main command would be allowed; git -C <path> does not match Bash(git status*) either. Running cd in its own call (the working directory persists) lets later commands match normally.

Vì sao thuộc tầng loopWhy the loop tier

Không liên quan tới Android hay repo này: đó là cách bộ lọc quyền của runtime đọc mọi dòng lệnh. Một câu trong ENGINE/POLICIES sẽ tránh được lần hỏi quyền ở mọi repo.

Nothing to do with Android or this repository: it is how the runtime's matcher reads every command line. One sentence in ENGINE/POLICIES saves the refusal in every repository.
